# Thanksgiving Porch

A single-page Thanksgiving card. `index.html` is the whole app (3D scene, fonts and sound are built in).
`og-image.jpg` is the 1200x630 picture shown in link previews on Facebook, WhatsApp, X, iMessage and others.

Share a personalised link by adding `#g-` plus the name in hex, or use the "Make my link" box at the end of the card.
